## TODO Management

Before modifying code:

1. Read TODO.md.
2. Identify the relevant incomplete task.

After modifying code:

1. Verify the implementation.
2. Run the appropriate tests/checks (`npm run lint`, `npm test`).
3. Update TODO.md.
4. Mark a task `[x]` only when all acceptance criteria are satisfied.

TODO.md is the source of truth for implementation progress.

Never mark a task complete without verification.
